*Modulation* is the process of embuing a signal inside a [[Carrier Wave]] in order to convey information through that wave.

# Taxonomy
* Modulation
	* Analog Carrier
		* Analog Data
			* [[Amplitude Modulation|AM]] (Amplitude Modulation)
				* The data signal varies the carrier's amplitude
			* [[Frequency Modulation|FM]] (Frequency Modulation)
				* The data signal varies the carrier's frequency
			* [[Phase Modulation|PM]] (Phase Modulation)
				* The data signal varies the carrier's phase
		* Digital Data
			* [[Amplitude Shift Keying|ASK]] (Amplitude Shift Keying)
				* The data signal varies the carrier's amplitude
			* [[Frequency Shift Keying|FSK]] (Frequency Shift Keying)
				* The data signal varies the carrier's frequency
			* [[Phase Shift Keying|PSK]] (Phase Shift Keying)
				* The data signal varies the carrier's phase
			* [[Quadrature Amplitude Modulation|QAM]] (Quadrature Amplitude Modulation)
				* The data signal varies both the carrier's amplitude and phase simultaneously
	* Digital Carrier
		* Analog Data
			* [[Pulse Amplitude Modulation|PAM]] (Pulse Amplitude Modulation)
				* The analog data varies the amplitude of each pulse
			* [[Pulse Width Modulation|PWM]] (Pulse Width Modulation)
				* The analog data varies the duration of each pulse
			* [[Pulse Position Modulation|PPM]] (Pulse Position Modulation)
				* The analog data varies the timing of each pulse
		* Digital Data
			* [[Pulse Code Modulation|PCM]] (Pulse Code Modulation)
				* The data is represented as a coded binary pulse pattern
			* [[Orthogonal Frequency Division Multiplexing|OFDM]] (Orthogonal Frequency Division Multiplexing)
				* The data is distributed across multiple frequency subcarriers, each independently modulated
