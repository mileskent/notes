*Radar* (Radio Detection And Ranging) is a system that uses radio waves to detect and locate objects. A [[Transmitter]] emits a radio [[Physics/Electromagnetism/Pulse|pulse]], which reflects off a target and returns to a [[Receiver]]. From the returned [[Computer Science/Computational Science/DigitalSignalProcessing/Signal|Signal]] you can extract:
- **Range** — time of flight of the pulse (round-trip time × c / 2)
- **Velocity** — Doppler shift of the return frequency
- **Angle** — direction the antenna was pointing when the return arrived (or via [[Monopulse Radar]])
- **Signature** — shape, size, and material properties from the return waveform
