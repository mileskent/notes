A collection of resources ([[Computer Science/Architecture/Function|Function]]s, variables, etc.) that can be used by multiple [[Program]]s at the same time, e.g. the GNU C Libary (glibc) provides the hooks for super commonly used [[Linux Kernel]] utilities such as [[malloc]] and printf.
