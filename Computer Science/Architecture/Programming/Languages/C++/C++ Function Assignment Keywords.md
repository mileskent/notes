
| **Construct**   | **Main Purpose**                                                                     |
| --------------- | ------------------------------------------------------------------------------------ |
| **`= 0`**       | Defines an interface contract and makes the class abstract.                          |
| **`= default`** | Requests compiler-generated default implementations while preserving type traits.    |
| **`= delete`**  | Disables calls, prevents unwanted conversions, and suppresses copying/instantiation. |
