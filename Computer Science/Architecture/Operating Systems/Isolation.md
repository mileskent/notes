In [[Operating System|Operating Systems]], *Isolation* is a core design principle that ensures different [[Process|processes]], [[User|users]], applications, and entities in general operate independently without interfering with one another.

If a [[Program]] crashes, encounters a bug, or is compromised by malware, isolation acts as a barrier that contains the problem.

# Isolation Mechanismss
* Memory Isolation, [[Virtual Memory]]
* Protection Rings
* Scheduling
* Filesystem Permissions
* Containers
* Virtualization
