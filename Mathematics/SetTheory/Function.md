A [[Mathematical Object]] that takes a set as an input, and outputs a set
* A mapping between sets
* Maps a [[Domain]] to a [[Codomain]]
* $f : A \rightarrow B$ is the function from $A$ to $B$ where $A$ and $B$ are [[Set]]s.
	* $f : A \rightarrow B \iff f \subseteq A \times B \land \{(a,b)\ |\ \forall a \in A,\ \exists! b \in B\ ((a,b) \in f)\}$
