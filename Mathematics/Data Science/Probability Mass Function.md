A *Probability Mass Function* is a [[Probability|Probability Function]] for a [[Discrete Distribution]], that is, where the [[Random Variable]] is Discrete. It is called a *mass* function, because each probability value per discrete [[Outcome]] is like a point mass.

* $|S| \leq \aleph_{0}$
* $\forall x \in S,\ f(x) = P(X=x)$
* $\forall x \in S,\ f(x) \geq 0$
* $\sum_{-\infty}^{\infty} f(x) = 1$
