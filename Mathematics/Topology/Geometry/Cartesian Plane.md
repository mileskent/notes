A coordinate system of orthogonal [[Real Number|real]]-valued axes. By default, this refers to the 2D plane $\mathbb{R}^2$ with axes $x$ and $y$, where each point is an ordered pair $(x, y)$. More generally, a Cartesian coordinate system can be defined over $\mathbb{R}^n$ for any $n$. Even [[Complex Plane|complex planes]] are denoted using cartesian coordinates, so they look like the cartesian plane, even if they are not the cartesian plane. The cartesian plane is a [[Euclidean Space]].
