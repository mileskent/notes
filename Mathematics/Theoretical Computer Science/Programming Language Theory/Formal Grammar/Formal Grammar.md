# Formal Definition
A formal grammar $G$ is defined as the 4-tuple
$$
G = (N, \Sigma, P, S)
$$
* where $N$ is nonterminals
* where $\Sigma$ is terminals
* where $P$ is production rules
* where $S$ is the start symbol
