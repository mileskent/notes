*Formal Semantics* is the rigorous mathematical study of semantics (meaning) in programming languages.

# Categories of Classification
- [[Denotational Semantics]]
- [[Operational Semantics]]
- [[Axiomatic Semantics]]

# Variations
- [[Algebraic Semantics]]
	- Use algebraic structures to describe program semantics
- Concurrency Semantics
	- Formal semantics for concurrent computations (actor model, process calculi)
- Game Semantics
	- Models computation as a game between a program and its environment
- Predicate Transformer Semantics
	- Developed by Dijkstra; describes a program fragment as a function transforming a postcondition to the precondition needed to establish it
