A *Multivector* is the general term in [[Geometric Algebra]] for an element of a [[Multivector Space]] (Geometric Algebra) $\mathbb{G}^n$. 

| Grade | Name      | Description                                               |
| ----- | --------- | --------------------------------------------------------- |
| 0     | Scalar    | A magnitude                                               |
| 1     | Vector    | An oriented magnitude                                     |
| 2     | Bivector  | An oriented plane formed by two vectors                   |
| 3     | Trivector | An oriented volume formed by three vectors                |
| $k$   | k-vector  | An oriented higher dimensional volume formed by k vectors |
